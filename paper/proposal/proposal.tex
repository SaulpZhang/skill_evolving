\section{Introduction}
\label{sec:introduction}

\subsection{Background and Motivation}

Large language model (LLM) agents have demonstrated competence on complex tasks in diverse environments, including embodied control, web navigation, and software engineering. An important mechanism underlying this breadth of capability is \emph{skill evolution}, through which an agent reflects on execution trajectories, extracts reusable knowledge, and accumulates that knowledge in a skill library for subsequent episodes.

Existing work has primarily addressed two components of this process. The first is \emph{skill quality}, namely the extraction of informative and reusable knowledge from trajectories. For example, SkillRL uses reflection to identify reusable strategies from successful episodes and recurrent failure modes from unsuccessful episodes. The second is \emph{skill utilization}, namely the organization, retrieval, and incorporation of skills into an agent's inference-time prompt. Representative approaches include structured skill banks with category-specific retrieval, vector-database retrieval, and dynamic prompting.

A critical dimension remains comparatively underexplored: \textbf{the order in which tasks are selected for practice.} Existing systems commonly cycle uniformly through a fixed task pool, sample tasks at random, or rely on hand-designed curricula that do not adapt to an agent's evolving competence. Since tasks can make substantially different contributions to skill progress, an adaptive selection policy may use the interaction budget more efficiently. This motivates the following question: \emph{Can task selection conditioned on an agent's current skill profile improve the efficiency and effectiveness of skill evolution in LLM agents?}

\subsection{Contributions}

We propose \textbf{SPG-Bandit} (Skill Profile Guided Bandit), a framework that casts task selection as a contextual bandit problem informed by an agent's multidimensional skill profile.

Our central idea is to use Multidimensional Item Response Theory (MIRT) to estimate latent proficiency across \(K\) skill dimensions and to select tasks that maximize expected progress on dimensions with lower estimated proficiency.

Specifically, our contributions are threefold:
\begin{enumerate}
    \item \textbf{Problem formulation.} We formalize task selection during LLM agent skill evolution as a non-stationary contextual bandit problem. The formulation captures both task-specific differences in expected skill progress and the multidimensional nature of agent competence.
    \item \textbf{Method.} We propose SPG-Bandit, which combines MIRT-based latent skill profiling with a gap-weighted sliding-window UCB policy. The method maintains an online proficiency estimate and selects tasks with high predicted progress on underdeveloped dimensions while accounting for estimation uncertainty.
    \item \textbf{General framework.} We provide a modular framework that can be integrated with existing skill-evolution methods and supports systematic evaluation of task-selection efficiency and downstream task performance.
\end{enumerate}

\section{Problem Formulation}
\label{sec:problem}

\subsection{Notation and Setup}

Consider an LLM agent interacting with a fixed task pool \(\mathcal{T} = \{\tau_1, \tau_2, \dots, \tau_M\}\) containing \(M\) tasks. At each round \(t = 1, 2, \dots\), the agent selects and executes a task \(\tau_t \in \mathcal{T}\) and observes a binary outcome \(y_t \in \{0,1\}\), indicating success or failure given its current skills.

The agent has a \emph{latent skill profile} \(\mathbf{s}_t \in [0,1]^K\), which represents proficiency across \(K\) distinct skill dimensions. This profile is unobserved and inferred from task outcomes. We define the estimated \emph{skill progress} after executing \(\tau_t\) as \(\boldsymbol{\delta}_t = \mathbf{s}_{t+1} - \mathbf{s}_t\). Accordingly, \(\boldsymbol{\delta}_t\) represents the change in the filtered latent-profile estimate following the observed task outcome and reflection update.

Each task \(\tau\) is associated with a \emph{task embedding} \(\mathbf{e}_\tau \in \mathbb{R}^{d_e}\), where \(d_e \in \mathbb{N}_{+}\), typically obtained by applying a sentence encoder to its natural-language goal description.

\subsection{Problem Definition}

We formalize adaptive task selection as a \emph{non-stationary contextual bandit} problem. At each round \(t\):

\begin{enumerate}
    \item The agent observes its context: its current skill profile \(\mathbf{s}_t\) and the embedding \(\mathbf{e}_\tau\) of every task \(\tau \in \mathcal{T}\).
    \item The agent selects an arm \(\tau_t \in \mathcal{T}\).
    \item The agent executes \(\tau_t\), observes the binary outcome \(y_t\), and updates its skills through reflection.
    \item The latent skill profile updates to \(\mathbf{s}_{t+1}\).
\end{enumerate}

% To prioritize underdeveloped skill dimensions, 
We define a \emph{gap weight} vector:

\begin{equation}
    \mathbf{g}_t = \operatorname{softmax}\!\left( \frac{\mathbf{1} - \mathbf{s}_t}{\gamma_g} \right),
    \label{eq:gap-def}
\end{equation}

where \(\gamma_g > 0\) is a temperature parameter. We use gap-weighted skill progress as the immediate bandit reward:

\begin{equation}
    r_t = \mathbf{g}_t^\top\boldsymbol{\delta}_t.
    \label{eq:reward}
\end{equation}

The goal is to maximize the expected cumulative reward:

\begin{equation}
    \max_{\pi} \; \mathbb{E}\left[ \sum_{t=1}^{T} r_t \;\middle|\; \tau_t \sim \pi(\cdot \mid \mathbf{s}_t, \{\mathbf{e}_\tau\}) \right],
    \label{eq:objective}
\end{equation}

where \(\pi\) denotes the task-selection policy and \(T\) is the number of rounds in the bandit phase. This reward prioritizes progress on underdeveloped dimensions without requiring an auxiliary objective.

We learn a surrogate model \(\hat{\boldsymbol{\delta}}_t(\tau)\) and use \(\mathbf{g}_t^\top \hat{\boldsymbol{\delta}}_t(\tau)\) as the bandit's estimated reward.


\section{Method}
\label{sec:method}

\subsection{Overview}

SPG-Bandit consists of a warmup phase and a bandit phase. During \textbf{warmup}, the agent samples tasks uniformly to obtain an initial set of interaction outcomes. A sequential MIRT model with temporal prior \(p(\mathbf{s}_{t+1}\mid\mathbf{s}_t)\) then infers a latent-profile sequence, corresponding skill deltas \(\{\boldsymbol{\delta}_t\}\), and task item parameters. These estimates provide supervision for an MLP that maps a task embedding and the current profile to a representation suitable for predicting skill progress.
    
During the \textbf{bandit phase}, the method computes a skill-gap vector \(\mathbf{g}_t\) from the current profile and evaluates every candidate task using a sliding-window neural linear UCB score. The selected task maximizes predicted gap-weighted progress together with an uncertainty bonus. The sliding window discards outdated interactions so that the ridge estimator remains responsive to changes in the context-to-progress relationship. After execution, an online Bayesian MIRT update produces the next profile estimate, and the resulting observation is inserted into the window.

\subsection{Key Components}

\paragraph{Multidimensional IRT (MIRT).}
We associate each task \(\tau\) with a \(K\)-dimensional discrimination vector \(\mathbf{a}_\tau \in \mathbb{R}^K\) and a scalar difficulty \(d_\tau \in \mathbb{R}\). Given the agent's current skill profile \(\mathbf{s} \in [0,1]^K\), its success probability on task \(\tau\) is:

\begin{equation}
    p_\tau(\mathbf{s}) = \sigma\!\left( \mathbf{a}_\tau^\top \mathbf{s} - d_\tau \right),
    \label{eq:mirt}
\end{equation}

where \(\sigma(x) = 1/(1 + e^{-x})\). We impose the element-wise constraint \(\mathbf{a}_\tau \geq 0\) and the scalar constraint \(d_\tau \geq 0\). The first constraint ensures that increasing any component of \(\mathbf{s}\) cannot reduce the predicted success probability. Consequently, the model aligns greater proficiency with stronger task performance. The nonnegative difficulty constraint further encodes a conservative prior over task difficulty and makes \(\mathbf{s}\) a directionally interpretable measure of agent capability.

After collecting \(N\) warmup outcomes \(\{(\tau_t,y_t)\}_{t=1}^N\), we estimate skill profiles and item parameters by alternating optimization. The temporal prior \(p(\mathbf{s}_{t+1}\mid\mathbf{s}_t)\) regularizes adjacent profiles and stabilizes inference. As in standard IRT, reliable estimation additionally requires a fixed scale convention and sufficient task coverage.

\textit{E-step.} With item parameters \(\{(\mathbf{a}_\tau, d_\tau)\}\) fixed, infer \(\mathbf{s}_{1:N+1}\) by maximizing the joint log-posterior
\[
\log p(\mathbf{s}_1) + \sum_{t=1}^{N}\left[\log p(y_t\mid\mathbf{s}_t,\mathbf{a}_{\tau_t},d_{\tau_t}) + \log p(\mathbf{s}_{t+1}\mid\mathbf{s}_t)\right],
\]
where \(p(\mathbf{s}_1)\) is a truncated Gaussian prior on \([0,1]^K\) centered at \(0.5\). In practice, the temporal prior is also a truncated Gaussian on \([0,1]^K\), centered at \(\mathbf{s}_t\).

\textit{M-step.} With profiles \(\{\mathbf{s}_t\}\) fixed, maximize each task's observation log-likelihood with respect to \((\mathbf{a}_\tau,d_\tau)\) using L-BFGS-B, subject to \(\mathbf{a}_\tau\geq0\), \(d_\tau\geq0\), and \(\ell_2\) regularization on \(\mathbf{a}_\tau\). Under these constraints, \(\mathbf{s}\uparrow\Rightarrow p_\tau(\mathbf{s})\uparrow\), so greater proficiency monotonically implies a higher predicted success probability.

We alternate the E-step and M-step until the objective converges.

\textit{Online update.} During the bandit phase, each observation \((y_t,\tau_t)\) refines the profile without rerunning the full alternating procedure. Given \(\mathbf{s}_t\) and \((\mathbf{a}_{\tau_t},d_{\tau_t})\), the updated profile is obtained as:

\begin{equation}
    \mathbf{s}_{t+1} = \arg\max_{\mathbf{s} \in [0,1]^K} \; \log p(y_t \mid \mathbf{s}, \mathbf{a}_{\tau_t}, d_{\tau_t}) + \log p(\mathbf{s} \mid \mathbf{s}_t).
\end{equation}



\paragraph{Delta prediction via MLP.}
To predict the improvement associated with a candidate task, we train a two-layer MLP \(\Phi\) that maps the concatenation of task embedding \(\mathbf{e}_\tau\) and current profile \(\mathbf{s}\) to a feature vector \(\boldsymbol{\phi}\in\mathbb{R}^{d_f}\), where \(d_f\in\mathbb{N}_{+}\). For hidden width \(d_h\), the parameters satisfy \(\mathbf{W}_1\in\mathbb{R}^{d_h\times(d_e+K)}\), \(\mathbf{b}_1\in\mathbb{R}^{d_h}\), \(\mathbf{W}_2\in\mathbb{R}^{d_f\times d_h}\), and \(\mathbf{b}_2\in\mathbb{R}^{d_f}\):

\begin{align}
    \mathbf{h} &= \max(\mathbf{W}_1 [\mathbf{e}_\tau; \mathbf{s}] + \mathbf{b}_1, 0), \\
    \boldsymbol{\phi} &= \mathbf{W}_2 \mathbf{h} + \mathbf{b}_2.
\end{align}

A linear pretraining head \(\mathbf{W}_3\in\mathbb{R}^{d_f\times K}\) predicts the expected delta as \(\hat{\boldsymbol{\delta}}=\mathbf{W}_3^\top\boldsymbol{\phi}\). The MLP is trained by minimizing mean squared error on the warmup dataset \(\{([\mathbf{e}_{\tau_i};\mathbf{s}_i],\boldsymbol{\delta}_i)\}_{i=1}^N\). After pretraining, \(\mathbf{W}_3\) is discarded and \(\Phi\) is fixed. Bandit decisions use the sliding-window ridge head \(\widehat{\mathbf{W}}_t\).

\paragraph{Gap-weighted UCB selection.}
To accommodate a non-stationary context-to-progress relationship, we maintain a sliding window containing the \(\ell\) most recent \emph{completed} interactions and fit a local ridge-regression head within that window. Let \(\mathcal{W}_t\) denote the indices stored in the buffer immediately before bandit round \(t\). The buffer is initialized with the final \(\ell\) warmup observations. For each buffered observation \(i\), define \(\boldsymbol{\phi}_i=\Phi([\mathbf{e}_{\tau_i};\mathbf{s}_i])\). The resulting covariance and response matrices are:

\begin{equation}
    \widehat{\mathbf{W}}_t = \mathbf{A}_t^{-1}\mathbf{B}_t,
    \quad
    \mathbf{A}_t = \lambda \mathbf{I}_{d_f} + \sum_{i \in \mathcal{W}_t} \boldsymbol{\phi}_{i}\boldsymbol{\phi}_{i}^\top,
    \quad
    \mathbf{B}_t = \sum_{i \in \mathcal{W}_t} \boldsymbol{\phi}_{i} \boldsymbol{\delta}_{i}^\top,
\end{equation}

For a candidate task \(\tau\), let \(\boldsymbol{\phi}_{t,\tau}=\Phi([\mathbf{e}_\tau;\mathbf{s}_t])\). The predicted delta is \(\hat{\boldsymbol{\delta}}_t(\tau)=\widehat{\mathbf{W}}_t^\top\boldsymbol{\phi}_{t,\tau}\). The matrix \(\mathbf{A}_t\) captures epistemic uncertainty through \(\boldsymbol{\phi}_{t,\tau}^\top\mathbf{A}_t^{-1}\boldsymbol{\phi}_{t,\tau}\). The UCB score is:

\begin{equation}
    \operatorname{score}_t(\tau) = \mathbf{g}_t^\top \hat{\boldsymbol{\delta}}_t(\tau) + \beta_t\lVert\mathbf{g}_t\rVert_2\sqrt{\boldsymbol{\phi}_{t,\tau}^\top\mathbf{A}_t^{-1}\boldsymbol{\phi}_{t,\tau}},
    \label{eq:score}
\end{equation}

The first term favors tasks with high predicted gap-weighted progress. The second term is a confidence bonus for the scalarized reward \(\mathbf{g}_t^\top\boldsymbol{\delta}_t\), where \(\beta_t>0\) is selected according to a ridge-regression confidence bound.

\paragraph{Sliding-window update.}
After observing \(\boldsymbol{\delta}_t\), we append \((\boldsymbol{\phi}_{t,\tau_t},\boldsymbol{\delta}_t)\) to the window and evict its oldest entry when the window exceeds size \(\ell\). The incremental updates are:

\begin{align}
    \mathbf{A}_{t+1} &= \mathbf{A}_t + \boldsymbol{\phi}_{t,\tau_t}\boldsymbol{\phi}_{t,\tau_t}^\top - \boldsymbol{\phi}_{\mathrm{old}}\boldsymbol{\phi}_{\mathrm{old}}^\top, \\
    \mathbf{B}_{t+1} &= \mathbf{B}_t + \boldsymbol{\phi}_{t,\tau_t}\boldsymbol{\delta}_t^\top - \boldsymbol{\phi}_{\mathrm{old}}\boldsymbol{\delta}_{\mathrm{old}}^\top, \\
    \widehat{\mathbf{W}}_{t+1} &= \mathbf{A}_{t+1}^{-1}\mathbf{B}_{t+1}.
\end{align}

The window size \(\ell\) controls the trade-off between estimation quality, which benefits from a larger sample, and responsiveness to non-stationarity, which benefits from recent observations.

\subsection{Algorithm}

Algorithm~\ref{alg:spg} summarizes the complete procedure.

\begin{algorithm}[t]
\caption{SPG-Bandit}
\label{alg:spg}
\begin{algorithmic}
\STATE {\bf Input:} Task pool \(\mathcal{T}\), warmup steps \(N\geq\ell\), bandit horizon \(T\), window size \(\ell\), feature dimension \(d_f\), gap temperature \(\gamma_g\), confidence radii \(\{\beta_t\}\), regularizer \(\lambda>0\), skill dimensions \(K\)
\STATE {\bf Phase 1: Warmup}
\FOR{\(i = 1\) to \(N\)}
    \STATE Select \(\tau_i \in \mathcal{T}\) uniformly
    \STATE Execute \(\tau_i\), observe \(y_i\in\{0,1\}\), and perform the skill-evolution update
    \STATE Store \((\tau_i,y_i)\)
\ENDFOR
\STATE Run sequential MIRT EM on \(\{(\tau_i,y_i)\}_{i=1}^{N}\) \(\to\) profiles \(\{\mathbf{s}_i\}_{i=1}^{N+1}\), deltas \(\{\boldsymbol{\delta}_i\}_{i=1}^{N}\), item parameters \(\{\mathbf{a}_\tau,d_\tau\}_{\tau\in\mathcal{T}}\)
\STATE Train and freeze MLP \(\Phi\) on \(\{([\mathbf{e}_{\tau_i};\mathbf{s}_i],\boldsymbol{\delta}_i)\}_{i=1}^{N}\)
\STATE Initialize \(\mathcal{W}\) with the latest \(\ell\) warmup tuples \((\boldsymbol{\phi}_i,\boldsymbol{\delta}_i)\), where \(\boldsymbol{\phi}_i=\Phi([\mathbf{e}_{\tau_i};\mathbf{s}_i])\)
\STATE Set \(\mathbf{A}=\lambda\mathbf{I}_{d_f}+\sum_{(\boldsymbol{\phi}_i,\boldsymbol{\delta}_i)\in\mathcal{W}}\boldsymbol{\phi}_i\boldsymbol{\phi}_i^\top\), \(\mathbf{B}=\sum_{(\boldsymbol{\phi}_i,\boldsymbol{\delta}_i)\in\mathcal{W}}\boldsymbol{\phi}_i\boldsymbol{\delta}_i^\top\), \(\widehat{\mathbf{W}}=\mathbf{A}^{-1}\mathbf{B}\), and \(\mathbf{s}=\mathbf{s}_{N+1}\)
\STATE {\bf Phase 2: Bandit}
\FOR{\(t = 1\) to \(T\)}
    \STATE Compute gap \(\mathbf{g}_t = \operatorname{softmax}((\mathbf{1} - \mathbf{s}) / \gamma_g)\)
    \FOR{each \(\tau \in \mathcal{T}\)}
        \STATE \(\boldsymbol{\phi}_{t,\tau}=\Phi([\mathbf{e}_\tau;\mathbf{s}])\), \(\hat{\boldsymbol{\delta}}_t(\tau)=\widehat{\mathbf{W}}^\top\boldsymbol{\phi}_{t,\tau}\)
        \STATE \(\operatorname{score}_t(\tau)=\mathbf{g}_t^\top\hat{\boldsymbol{\delta}}_t(\tau)+\beta_t\lVert\mathbf{g}_t\rVert_2\sqrt{\boldsymbol{\phi}_{t,\tau}^\top\mathbf{A}^{-1}\boldsymbol{\phi}_{t,\tau}}\)
    \ENDFOR
    \STATE \(\tau_t=\arg\max_{\tau\in\mathcal{T}}\operatorname{score}_t(\tau)\)
    \STATE Execute \(\tau_t\) and observe \(y_t\)
    \STATE \(\mathbf{s}_{\mathrm{new}}\gets\textsc{BayesUpdate}(\mathbf{s},\mathbf{a}_{\tau_t},d_{\tau_t},y_t)\)
    \STATE \(\boldsymbol{\delta}_t\gets\mathbf{s}_{\mathrm{new}}-\mathbf{s}\) and \(\mathbf{s}\gets\mathbf{s}_{\mathrm{new}}\)
    \STATE Append \((\boldsymbol{\phi}_{t,\tau_t},\boldsymbol{\delta}_t)\) to \(\mathcal{W}\)
    \STATE \(\mathbf{A}\mathrel{+}=\boldsymbol{\phi}_{t,\tau_t}\boldsymbol{\phi}_{t,\tau_t}^\top\) and \(\mathbf{B}\mathrel{+}=\boldsymbol{\phi}_{t,\tau_t}\boldsymbol{\delta}_t^\top\)
    \IF{\(|\mathcal{W}| > \ell\)}
        \STATE Pop oldest \((\boldsymbol{\phi}_{\mathrm{old}},\boldsymbol{\delta}_{\mathrm{old}})\) from \(\mathcal{W}\)
        \STATE \(\mathbf{A}\mathrel{-}=\boldsymbol{\phi}_{\mathrm{old}}\boldsymbol{\phi}_{\mathrm{old}}^\top\) and \(\mathbf{B}\mathrel{-}=\boldsymbol{\phi}_{\mathrm{old}}\boldsymbol{\delta}_{\mathrm{old}}^\top\)
    \ENDIF
    \STATE \(\widehat{\mathbf{W}}=\mathbf{A}^{-1}\mathbf{B}\)
\ENDFOR
\end{algorithmic}
\end{algorithm}

\section{Theoretical Analysis}
\label{sec:theory}

Because the relationship between context and skill progress may change over time, expected task rewards can be non-stationary. In this section, \(t\in\{1,\ldots,T\}\) indexes only bandit-phase rounds. We analyze the dynamic \emph{pseudo-regret} of SPG-Bandit under the sliding-window ridge estimator described in Section~\ref{sec:method}.

\subsection{Non-stationary Setting}

For each candidate task \(\tau\), define \(\boldsymbol{\phi}_{t,\tau}=\Phi([\mathbf{e}_\tau;\mathbf{s}_t])\) and the conditional mean skill progress
\[
\boldsymbol{\mu}_t(\tau)=\mathbb{E}[\boldsymbol{\delta}_t(\tau)\mid\mathbf{s}_t].
\]
The expected scalar reward is \(q_t(\tau)=\mathbf{g}_t^\top\boldsymbol{\mu}_t(\tau)\). Let \(\tau_t^*\in\arg\max_{\tau\in\mathcal{T}}q_t(\tau)\) be the dynamic oracle action. We evaluate the dynamic pseudo-regret

\begin{equation}
    R_T=\sum_{t=1}^{T}\bigl[q_t(\tau_t^*)-q_t(\tau_t)\bigr].
    \label{eq:pseudo-regret}
\end{equation}

This quantity is a pseudo-regret because it compares conditional expected rewards rather than realized noisy outcomes. Let \(\mathcal{F}_{t-1}\) denote the history available before round \(t\). Boundedness of \(\mathbf{s}_t\) alone does not imply sublinear non-stationarity. We therefore impose a separate variation condition on the time-varying reward model.

\subsection{Assumptions}

\begin{enumerate}
    \item \textbf{(Time-varying linear delta model.)} There are matrices \(\{\mathbf{W}_t^*\}_{t=1}^{T}\), where \(\mathbf{W}_t^*\in\mathbb{R}^{d_f\times K}\), such that \(\boldsymbol{\delta}_t(\tau)=\mathbf{W}_t^{*\top}\boldsymbol{\phi}_{t,\tau}+\boldsymbol{\varepsilon}_t(\tau)\), with \(\mathbb{E}[\boldsymbol{\varepsilon}_t(\tau)\mid\mathcal{F}_{t-1},\tau]=\mathbf{0}\).
    \item \textbf{(Boundedness and noise.)} \(\lVert\boldsymbol{\phi}_{t,\tau}\rVert_2\leq1\), \(\lVert\mathbf{W}_t^*\rVert_F\leq S\), and, for every \(\mathbf{u}\) satisfying \(\lVert\mathbf{u}\rVert_2\leq1\), the scalar \(\mathbf{u}^\top\boldsymbol{\varepsilon}_t(\tau)\) is conditionally \(\sigma\)-sub-Gaussian.
    \item \textbf{(Parameter-path variation.)} The reward-model variation is \(P_T=\sum_{t=1}^{T-1}\lVert\mathbf{W}_{t+1}^*-\mathbf{W}_t^*\rVert_F\).
    \item \textbf{(Calibrated window and coverage.)} Before the first bandit round, warmup provides \(\ell\) calibration observations generated under \(\mathbf{W}_1^*\). At each bandit round, the window contains exactly \(\ell\) observations and satisfies \(\sum_{i\in\mathcal{W}_t}\boldsymbol{\phi}_i\boldsymbol{\phi}_i^\top\succeq\kappa\ell\mathbf{I}_{d_f}\) for a constant \(\kappa>0\).
\end{enumerate}

Assumption~1 matches the algorithmic regression target, which is \(\boldsymbol{\delta}_t\) rather than \(\mathbf{s}_{t+1}\). Assumption~2 controls the scale of features, parameters, and noise. Assumption~3 quantifies non-stationarity through the parameter path. Assumption~4 isolates the effect of non-stationarity from an ill-conditioned design matrix. For a failure probability \(\rho\in(0,1)\), Appendix~\ref{app:proof} provides a detailed high-probability proof.

\subsection{Dynamic Regret Decomposition}

Let \(w_t(\tau)=\sqrt{\boldsymbol{\phi}_{t,\tau}^\top\mathbf{A}_t^{-1}\boldsymbol{\phi}_{t,\tau}}\) and \(\widehat{\mathbf{W}}_t=\mathbf{A}_t^{-1}\mathbf{B}_t\). Under Assumptions~1--4, Appendix~\ref{app:proof} proves that, with probability at least \(1-\rho\),

\[
\left|\mathbf{g}_t^\top(\widehat{\mathbf{W}}_t-\mathbf{W}_t^*)^\top\boldsymbol{\phi}_{t,\tau}\right|
\leq \beta_t\lVert\mathbf{g}_t\rVert_2w_t(\tau)+D_t,
\]

where \(\beta_t=\tilde{O}(\sigma\sqrt{K d_f}+\sqrt{\lambda}S)\) is a confidence radius and \(D_t\) is the explicitly bounded bias from stale observations. Since the policy selects the task with the largest UCB score, approximate optimism yields
\[
q_t(\tau_t^*)-q_t(\tau_t)
\leq 2\beta_t\lVert\mathbf{g}_t\rVert_2
 w_t(\tau_t)+2D_t.
\]

Because \(\mathbf{g}_t\) is a softmax vector, \(\lVert\mathbf{g}_t\rVert_2\leq1\). Assumption~4 gives \(w_t(\tau)\leq(\lambda+\kappa\ell)^{-1/2}\) for every candidate task. The detailed counting argument in Appendix~\ref{app:proof} gives \(\sum_{t=1}^{T}D_t\leq \ell^2P_T/\sqrt{\lambda(\lambda+\kappa\ell)}\). Therefore, with \(\beta=\max_{t\leq T}\beta_t\),

\begin{equation}
    R_T \leq \underbrace{\frac{2\beta T}{\sqrt{\lambda+\kappa\ell}}}_{\text{estimation}}+\underbrace{\frac{2\ell^2P_T}{\sqrt{\lambda(\lambda+\kappa\ell)}}}_{\text{drift}}.
    \label{eq:decomposition}
\end{equation}

\subsection{Optimal Window and Regret Bound}

For \(P_T>0\), when \(\kappa\ell\geq\lambda\), balancing the two terms yields the following feasible integer window size:

\begin{equation}
    \ell^*=\min\!\left\{T,\max\!\left\{\left\lceil\frac{\lambda}{\kappa}\right\rceil,\left\lceil\left(\frac{\beta T\sqrt{\lambda}}{P_T}\right)^{1/2}\right\rceil\right\}\right\},
\end{equation}

and the corresponding cumulative regret bound, up to universal constants:

\begin{equation}
    R_T=O\!\left(\frac{(\beta T)^{3/4}P_T^{1/4}}{\kappa^{1/2}\lambda^{1/8}}\right).
    \label{eq:bound}
\end{equation}

If \(P_T=0\), the drift term vanishes and \(\ell=T\) minimizes the displayed bound. If \(P_T=o(T)\) and \(\beta\), \(\kappa^{-1}\), and \(\lambda^{-1}\) grow at most polylogarithmically, then the bound is sublinear. For example, if \(P_T=O(T^\nu)\) for \(\nu<1\), then

\begin{equation}
    R_T=\tilde{O}\!\left(T^{(3+\nu)/4}\right)=o(T).
\end{equation}
